# Failure modes

Named so the agent can catch itself.

| name | what it looks like | fix |
|---|---|---|
| **keyword trap** | agent Googles the whole sentence | run `find` |
| **platform soup** | youtube+tiktok+ig+linkedin on “find people” | one scenario default |
| **score mixing** | “this LinkedIn beat that YouTuber” | presence vs engagement |
| **known as new** | already-outreached names as the lead | roster + novelty |
| **LinkedIn-without-engagement** | ranking `/in` URLs by fake views | presence score, say it |
| **people-at-companies** | company search for “people at X companies” | person-words win |
| **compare-as-blog** | invented verdict headers | paste `table` |
| **cookie LinkedIn** | “log in and scrape” | refuse; this skill is public index |
| **send the outreach** | draft 40 emails inside the find | export CSV, stop |
| **wrong folder** | running Higgsfield `make install` | zip `who-finder/` only |

If `doctor` is `skipped-unconfigured`, stop. Inventing names is worse than a missing key.
