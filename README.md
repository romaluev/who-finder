# who-finder

Agent skill + CLI: **deep public research on people or companies**. Creators are one scenario, not the product.

Give it a brief in plain English. It works out what kind of search that is, plans the queries itself, pulls public profiles, scores every result against your ICP with attributed reasons, ranks by priority, and remembers who it already showed you so outreach never gets the same name twice.

Python 3.11+. No pip, no build step. One dependency: a [ScrapeCreators](https://scrapecreators.com) API key.

## Install

Copy this whole folder (the one containing `SKILL.md`) to one of:

- project skills: `.claude/skills/who-finder/`
- Cursor user skills: `~/.cursor/skills/who-finder/`
- Claude user skills: `~/.claude/skills/who-finder/`

```bash
export SCRAPECREATORS_API_KEY=...        # your own key
python3 scripts/who_finder.py doctor --agent
```

`doctor` tells you exactly which of the four states you are in: `ready`, `skipped-unconfigured`, `auth-failed`, `error`.

## Teach it your ICP

Fit scoring is a local JSON file you own. Without one, the engine derives a topic gate from your brief and applies generic seniority rules.

```bash
python3 scripts/who_finder.py icp init      # editable template
python3 scripts/who_finder.py signals       # signal names you can score
```

```json
{
  "must_any": ["ai video", "generative video"],
  "boost": { "founder": 15, "head of": 12, "agency": 10 },
  "penalty": { "student": -20, "intern": -15 },
  "audience": { "min": 1000, "sweet_min": 10000, "sweet_max": 2000000, "weight": 20 },
  "geo": { "prefer": ["united states"], "weight": 8 },
  "signals": { "hiring": 10, "funded": 12 }
}
```

If results feel off, edit this file. That is the intended control surface — the scoring stays inspectable instead of drifting into model taste.

## CLI

```bash
B="python3 scripts/who_finder.py"

$B doctor --agent                                  # health + credits
$B which "who should we pitch" --agent             # phrase -> command
$B find "founders of AI video tools" --deep 10     # the main verb
$B find "AI video ads" --scenario creators --deep 10
$B report --status new                             # re-render the brief, 0 credits
$B enrich person/linkedin/jane-doe                 # dossier for one name
$B expand company/linkedin/acme                    # its staff + lookalikes, 0 credits
$B show person/youtube/adlab                       # full dossier card
$B mark person/linkedin/jane-doe --status outreached
$B export --status new --band strong --out handoff.csv
$B import known-customers.csv                      # seed a skip list
```

Add `--agent` to any command for JSON.

### Cost

| call | credits |
|---|---|
| each query angle in a plan | 1 |
| each enriched entity (`--deep N`) | 1, or 0 on a YouTube/TikTok cache hit |
| `report`, `expand`, `show`, `export`, `mark`, `import` | 0 |

`find "brief" --deep 10` typically costs ~15 credits. Bare `find` costs one per angle and returns names only.

## Where the data lives

`.who-finder/roster.sqlite` in your working directory: entities, hits, dossiers, ICP scores and score history over time. Override with `WHO_FINDER_HOME` or `--db`. Two people can share a roster by pointing `--db` at the same file.

A name stays `new` until *you* mark it. Re-running the same search does not quietly retire it into "known" — the outreach queue is only cleared by an actual decision.

## What it does not do

Send messages. Log into LinkedIn or use cookies, Sales Navigator, or a member session — LinkedIn here is Google-indexed public URLs plus vendor profile endpoints. Act as a CRM. Print a job title it did not receive.

## Tests

```bash
python3 -m pytest tests -q      # 72 tests, no network, no key required
```

The suite fakes the HTTP layer with the exact response shapes ScrapeCreators documents, so the whole pipeline — plan, search, identity, roster, enrich, fit, rank, render — is covered offline.
